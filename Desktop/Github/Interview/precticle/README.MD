# 🎮 Guess My Number Game

A simple and interactive **Guess My Number** game built using **HTML, CSS, and JavaScript**. The player has to guess a secret number between **1 and 20**. Every incorrect guess decreases the score, and the game keeps track of the highest score.

---

## 📌 Project Description

This project is a retro-style number guessing game where the user enters a number and tries to match the randomly generated secret number. The game provides hints if the guess is too high or too low and updates the score after every attempt.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## ✨ Features

- 🎯 Guess a random number between **1 and 20**.
- ✅ **Check!** button to verify the guess.
- 🔄 **Again!** button to restart the game.
- 📉 Score decreases by 1 for every wrong guess.
- 🏆 High Score updates when a better score is achieved.
- 📱 Fully responsive design for desktop and mobile devices.

---

## 🎮 How to Play

1. Open `index1.html` in your web browser.
2. Enter a number between **1 and 20**.
3. Click the **Check!** button.
4. The game will display one of these messages:
   - **Correct Number!** 🎉
   - **Too High!**
   - **Too Low!**
   - **Invalid Guess!**
5. Click **Again!** to start a new game.

---

## 📊 Game Rules

| Rule | Value |
|------|-------|
| Number Range | 1 – 20 |
| Starting Score | 20 |
| Wrong Guess | Score decreases by 1 |
| Correct Guess | High Score updates if score is higher |
