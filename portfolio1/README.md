# Workfolio - Personal Portfolio Website

A modern, responsive, and elegant dark-themed portfolio website built with **React**, **Bootstrap**, and **CSS3**. Designed specifically for UI/UX designers and front-end developers to showcase their experience, skills, case studies, and client testimonials.

---

## 🚀 Live Demo & Preview

* **Theme:** Modern Dark Neon Blue (`#020b1f`, `#23b7ff`)
* **Responsive:** Fully optimized for Mobile, Tablet, and Desktop screens.

---

## ✨ Features

- **Hero Section:** Highlighting bio, availability badge, profile avatar, and direct CTA buttons.
- **Trusted Companies Banner:** Client logos and social media links.
- **About Me:** Clean summary, years of experience, shipped projects count, and awards.
- **Services (What I Do):** Structured interactive cards for design & engineering offerings.
- **Skills & Tools:** Visual progress bars and skill tags (Figma, React, TypeScript, etc.).
- **Work Experience & Education:** Two-column interactive timeline view with milestone cards.
- **Selected Work / Projects:** Showcase case studies with tags, images, and quick links.
- **Client Testimonials (Kind Words):** Clean review cards with star ratings and client avatars.
- **Process (How I Work):** 4-step workflow breakdown (Discover, Design, Build, Launch).
- **Call-to-Action (CTA):** Eye-catching glow effect container for project inquiries.
- **Contact Form & Footer:** Working layout for queries, social icons, and address details.

---

## 🛠️ Built With

* [React.js](https://react.dev/) - Front-end JavaScript Library
* [Bootstrap 5](https://getbootstrap.com/) - Responsive Grid and Utilities
* [React Icons](https://react-icons.github.io/react-icons/) - Modern SVG icons (`react-icons/fa6`, `react-icons/hi2`, `react-icons/fi`, `react-icons/bs`)
* Custom CSS3 - Dark radial gradients, custom scrollbars, animations, and glow effects.
